Privacy Policy

kingdom-rclone · last updated 7 November 2026

kingdom-rclone is a private tool, not a public service. Its only user is its owner, Jordan King. It lets the owner's own home server open and save files in the owner's own Google Drive, using the open-source program rclone.

What data it accesses

With the owner's permission, it reads and writes files in the owner's Google Drive. It accesses no other Google data and no data of other people's accounts.

How the data is used and stored

Files are transferred directly between Google Drive and the owner's own server. They are used only by the owner's own scripts and tools on that server. The sign-in token is stored only on that server.

Sharing

No data is sold, shared with or transferred to anyone else. It is not used for advertising, analytics or training models.

Google API Services User Data Policy

kingdom-rclone's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time on the Google Account permissions page.
